# Task 4 – Hypothesis Testing (A/B Test)

## Dataset
E-commerce A/B Test Data

## Objective
To test whether a new website design improves conversion rate.

## Hypotheses
H0: New design ≤ Old design  
H1: New design > Old design  

## Tests Performed
- Two-proportion Z-test
- Confidence interval analysis
- Chi-square test
- T-test

## Key Findings
- New design significantly improves conversion rate
- No adverse effects observed
