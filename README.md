# Soft-Nexis-Internship

# Task 2 – Exploratory Data Analysis (EDA)

## Dataset
Titanic Dataset

## Objective
To explore data patterns, relationships, and anomalies using visualization and statistics.

## Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Google Colab

## Key Analysis
- Distribution analysis of Age, Fare
- Survival analysis by gender and class
- Correlation heatmap
- Outlier detection using boxplot and Z-score
- Advanced visualizations (FacetGrid, Pairplot)

## Key Insights
- Females and first-class passengers had higher survival rates
- Fare positively correlates with survival
- Age impacts survival non-linearly
