# Task 3 – Time Series Analysis

## Dataset
Air Passengers Dataset (1949–1960)

## Objective
To analyze trend and seasonality and forecast future passenger traffic.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Statsmodels
- Google Colab

## Steps Performed
- Time series visualization
- Trend and seasonality decomposition
- Moving average smoothing
- ARIMA forecasting
- RMSE evaluation

## Key Insights
- Strong upward trend and yearly seasonality
- ARIMA captured cyclic behavior effectively
- Forecast indicates continued growth
